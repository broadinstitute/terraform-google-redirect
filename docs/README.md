# terraform-google-redirect

Terraform module to build http/https redirects totally using GCP load balancer
components.

## Compatibility

This module is meant for use with Terraform 1.3+ and tested using Terraform
1.12. If you find incompatibilities using Terraform >=1.11, please open an
issue.

## Module

There are three modules within this repository located under the `modules`
directory.

### certificates

The `certificates` module is used internally to do the work of generating all
certificate-related resources to make a working redirect. This module can be
used externally, but it is tightly linked to the other modules, so changes
shouldn't be made that could adversely affect the other modules.

### http_redirects

This module is the older version of the redirect module that would create
separate forwarding rules, proxies, etc. for each set of redirects. This is
being decommissioned in favor of the `http_lb_redirects` module.

### http_lb_redirects

This is the primary module for this repository that should be used to construct
http redirects in GCP.
